# 手机／普通聊天窗口版

适合只能使用 DeepSeek Chat 等普通聊天窗口、不能运行本地 Agent 工具的用户。手机浏览器负责计算盘面，聊天模型结合配套知识文件解读你提出的问题。

## 下载文件

- [index.html — 手机排盘页](index.html)
- [qimen-chat.md — 解盘知识文件](qimen-chat.md)

当前提供文件下载，尚未开通在线排盘网站。GitHub 中的 HTML 文件页显示源码；需要先下载，再用浏览器打开。

可以在仓库首页选择 **Code → Download ZIP**，解压后进入 `mobile/`。也可以分别下载上述两份文件，保存在同一个文件夹里，以便排盘页中的“下载解盘知识文件”链接找到配套文件。

## 使用步骤

1. 用浏览器打开 `index.html`。页面首次打开会采用当前北京时间；如果问过去或指定时刻，修改日期与时间，选定盘式和设置，点击 **排盘**。
2. 点击 **下载 MD 盘文**，保存本次生成的 `奇门盘_*.md`。如不方便保存文件，可点 **复制 MD 盘文**；自动复制不可用时，展开“查看 / 手动复制完整 Markdown 盘文”，生成文本后长按全选、复制。
3. 在同一个聊天窗口上传 **`qimen-chat.md` 和本次 `奇门盘_*.md`**，并说明实际问事。如果本次盘文通过复制获得，则上传知识文件后，把完整盘文粘贴进聊天。
4. 继续追问可以沿用同一盘。需要更换时间或设置时，重新排盘并导出新的盘文，告诉聊天模型使用哪一份。

例如：

> 请读取我上传的 qimen-chat.md 和本次奇门盘文件。我的问题是：这次工作调动能否落实，主要阻力在哪里？请按已有盘面解读，不要重新排盘。

## 两种 Markdown 文件有什么区别？

| 文件 | 内容 | 什么时候需要 |
|---|---|---|
| `qimen-chat.md` | 解盘方法和 20 份理论资料 | 新建聊天时提供，后续同一聊天通常可以沿用 |
| `奇门盘_*.md` | 本次时间、设置、四柱、九宫字段及计算步骤 | 每次采用新盘时重新导出 |

知识文件约 145 KB，适合以附件上传。它不会替聊天模型从日期计算九宫盘；盘面由 HTML 内置引擎生成，无需上传 PNG 截图。理论资料之间的链接已经改为文内跳转，不需要额外下载原 Skill 的参考目录。

## 操作提示

- 时间输入按 **北京时间 UTC+8** 解释；“此刻”按钮会从设备当前时钟换算到北京时间。
- “按局复核”模式使用手动选定的阴阳遁、局数和起盘干支，不会计算真实公历四柱；导出的盘文会明确记录这一点。
- 修改日期后，要点击“排盘”再导出；页面会拒绝把未重新计算的旧盘当作新输入导出。
- HTML 自带引擎、节气数据和样式，排盘与盘文生成在浏览器本地完成，无需 Node.js、Python 或排盘服务器。向聊天模型上传附件时，使用相应聊天平台。
- 如果聊天软件的附件预览只显示源码或不能操作，保存文件后改用支持本地 HTML 的浏览器打开。

## 版本与来源

手机聊天版为 **0.1**，盘文导出格式为 **0.1.0**，内嵌排盘引擎为 **0.4.1**。知识文件来自解盘模块 **0.2.3** 的 20 份理论资料。

本目录以原手机 HTML 和 `qimen-chat.md` 为基础整理：首次打开改用当前北京时间，增加配套文件入口，并将知识文件的资料间链接改为文内跳转。排盘引擎和理论正文保持原有内容。
