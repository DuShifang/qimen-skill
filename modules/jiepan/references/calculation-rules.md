# 确定计算与盘面状态

读取结果与派生计算分开保存。`chart` 返回原字段、原状态和 JSON pointer；其他命令输出独立 `derivedVersion/method/state/inputs/value`。原图未印的格子仍是 unknown，计算结果不写回源 JSON。比较发现冲突时同时保留源值和派生值，由分析者核对所用柱、盘式与记录口径。

## 明确干支求旬首、旬空

输入必须明确是哪一柱：`year/month/day/hour`。日柱与时柱分别计算，不把某一柱的空亡当成全盘统一空亡。这里从已明确的干支开始，不计算公历、节气或日界；需要从日期起盘时调用 qimen-paipan。

六十甲子按甲子起序，每十个干支一旬。先验证输入是六十个合法组合之一，再求它所属的十位区间：

| 旬首 | 六甲所遁仪 | 旬空 | 旬空支所在宫 |
|---|---|---|---|
| 甲子 | 戊 | 戌、亥 | 乾六 |
| 甲戌 | 己 | 申、酉 | 坤二、兑七 |
| 甲申 | 庚 | 午、未 | 离九、坤二 |
| 甲午 | 辛 | 辰、巳 | 巽四 |
| 甲辰 | 壬 | 寅、卯 | 艮八、震三 |
| 甲寅 | 癸 | 子、丑 | 坎一、艮八 |

`cycleIndex` 为从甲子开始的 0—59 序号；`voidPalaces` 是空支对应宫去重后的列表。甲丑等不成立的阴阳组合、错误字符或多余字符直接报错。所选柱缺失、null 或空字符串时返回 unknown。

这项计算不使用 profile，profile 为空或是本工具未实现的其他方法都不影响明确干支的旬首。结果原样记录 profile 并标明 `profileUsed=false`，不把它替换为默认盘式。盘面读取和门局识别仍各自检查所需的盘式。

原接口的顶层 `xun/hidden/voidBranches/voidPalaces` 可能按起盘柱生成。只有源记录明确 `activePillar` 且与本次所选柱相同，才比较一致或冲突；不同柱记录为 `differentPillar`，未声明作用柱记录为 `unscoped`。原值为 unknown 时保留 unknown，同时展示能从干支求出的派生结果。

理论依据：《开悟之门》第一章第三节“十天干”关于六十甲子、六甲旬空的说明，以及地支与九宫的对应关系。实现采用有限序列表查找，已与现有排盘引擎的 `gz/cycleIndex/board` 六十组结果逐项核对；不新增历法引擎。

## 八门全局伏吟、反吟

本算法处理门转布局，包括已支持 profile 中的 `zhuanpan` 与 `xingfeimenzhuan`，可用于其时家、日家、月家盘面的几何识别。`feipan` 与 `shenzhuanfeipan` 在本算法返回 notApplicable。profile 未明确时返回 unknown；只有已明确实际盘式，才可通过 `--profile` 补充本次计算条件。补充值与原 profile 冲突时返回 unknown，保留双方。

| 八门 | 本宫 | 对冲宫 |
|---|---|---|
| 休门 | 坎一 | 离九 |
| 死门 | 坤二 | 艮八 |
| 伤门 | 震三 | 兑七 |
| 杜门 | 巽四 | 乾六 |
| 开门 | 乾六 | 巽四 |
| 惊门 | 兑七 | 震三 |
| 生门 | 艮八 | 坤二 |
| 景门 | 离九 | 坎一 |

八个外宫门位齐全、八门各出现一次后，才给出全局结论：八门全部在本宫为门伏吟，全部在各自对冲宫为门反吟；信息完整但两者均不满足时为 `none`。局部本宫或对冲匹配会列出，不能升级为全局格局。门位缺失、状态不可用、门名异常或八门重复时返回 unknown，`value=null`，不能读成“不伏吟且不反吟”。这项结果只涉及门层，不代替星层、六甲层或综合格局判断。

中心门标记单独保留。中宫无已知门标记时，只比较完整的外八宫；中宫有门标记时，不根据通用 `hostPalace` 自动挪门。只有资料明确其实际寄宫，才提供 `--center-door-host`：中心与寄宫同名时作为寄宫注记；寄宫门位未知或明确为空时，可生成单独的寄宫投影参与八门核对，并保留原寄宫 unknown／空值；寄宫已有不同门、寄宫状态不适用、中心为不属八门的“中门”等情况返回 unknown。中心寄宫不会修改原字段，也不会凭一个中心标记补出其他缺失门位。

理论依据：《神奇之门》奇门常用凶格中关于门在本宫为伏吟、在对冲宫为反吟的定义；上述“全八门核齐后才作全局识别”是本工具的计算判定范围。中心投影要求明确寄宫信息，是读取书盘时的输入处理约定。

## 固定宫五行关系

坎一水，坤二、中五、艮八土，震三、巽四木，乾六、兑七金，离九火。按木生火、火生土、土生金、金生水、水生木，以及木克土、土克水、水克火、火克金、金克木，返回前宫对后宫的同五行、生、受生、克或受克关系。

这里使用固定地盘宫五行，不把宫中星门干的本五行混入宫间关系，也不自动计算旺衰、主客、支持力度或吉凶分数。理论依据：《开悟之门》第一章第二节关于九宫五行，以及第三节通常五行生克的说明。
